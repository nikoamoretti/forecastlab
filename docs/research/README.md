# Research notes

Scouting passes that feed ForecastLab questions. A scouting pass asks "what could change?" before the forecasting methods ask "how likely, when, how much?". These notes are research inputs, not forecasts or accuracy claims.

Includes an analyst-judgment ranking and scenarios. |
| [GPU candidate questions](gpu_scouting_questions_2026-10.json) | 2026-10-03 | 15 candidate questions (binary and numeric). Each has precise resolution criteria, a public resolution source and a resolution date between 2026-11-10 and 2027-12-31. |

Every factual claim in a note links to a dated source. The labels say what kind of claim it is: measured [M], third-party estimate [E], unconfirmed report [R], calculation from cited inputs [AC], or analyst judgment [AJ]. Pages fetched while researching are not committed; the notes keep their URLs and access dates.

Numeric questions need value forecasts, which the binary-only pipeline does not produce yet. Binary candidates can be entered as general binary questions.
