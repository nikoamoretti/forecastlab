Synthetic disinflation reference-class note

SYNTHETIC WORKFLOW EVIDENCE — NOT A REAL SOURCE DOCUMENT.

This static note is a synthetic historical reference class dated 9 February 2024. It does not state or imply the later September CPI outcome.

Past disinflation episodes show that twelve-month inflation can fall quickly when earlier large monthly increases leave the comparison window. Progress can also stall when housing or labor-intensive services remain persistent.

A base-rate estimate should compare episodes with similar starting inflation, policy restraint, and supply normalization. It should also test an adversarial scenario in which favorable base effects fade before underlying monthly inflation has reached a threshold-consistent pace.
